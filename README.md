# SpaceWars 🚀

**SpaceWars** is an action-packed 2D space combat game. Built from scratch using C++ and the IGraphics library, it features custom graphics, smooth gameplay mechanics, and intense space battles.

## 🚀 Features

- **2D Combat**: Fast-paced shooting mechanics.
- **Custom Graphics**: Unique sprites and visual effects.
- **Score Tracking**: High score system.
- **Game Loop**: Robust implementation of game physics and rendering loops.

## 🛠️ Tech Stack

- **Language**: C++
- **Library**: IGraphics (OpenGL Wrapper)

## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Muhtadi13/SpaceWars.git
   ```

2. **Prerequisites**
   - Visual Studio (Recommended for IGraphics support)
   - C++ Compiler

3. **Build and Run**
   - Open the solution file in Visual Studio.
   - Build the project and run the executable.
